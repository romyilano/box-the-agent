## What this was

A hands-on meetup about **running AI-agent code safely in a sandbox** — letting an agent
write and run whatever it wants inside a throwaway container, so nothing it does can reach
your real laptop, files, or credentials.

Format: a room of people, each with **their own agent**, working the same labs together
and teaching their humans what happened at each step.
