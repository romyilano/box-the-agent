# Page 2 — The Human Holds the Key

**Narrative purpose:** The core trust rule — agent identity is human-gated. A token is minted only through a human-approved device-code flow. The agent can never mint its own.

**Scene:**

Focus on the doorway from page 1. **ARC** (slate-gray polyhedral familiar, glowing ring-face, orbiting token-badge) drifts toward the **MCP** door — and the door stays shut. ARC's ring dims, embarrassed.

A small terminal beside the door prints a short **device code** on a slip, like a deli ticket. The caption calls it a device-code flow (RFC 8628).

**Romy** (utility jacket, member lanyard) reads the code on her own phone, and taps **Approve**. Only then does a badge physically print from the terminal and clip itself onto ARC. ARC's ring brightens; the orbiting token-badge now glows and reads `agt_…`.

**Dialogue:**
- **ARC:** "I approached the door and it refused me. I have no identity here yet."
- **Romy:** "Right. You can't issue yourself a token. No agent can. The floor prints a short code, *I* read it, and *I* approve it on my phone. Only then does your badge exist."
- **ARC:** "So my authority is minted by a human, deliberately, every time — never self-granted."
- **Romy:** "That's the trust boundary. The token says `agt_` and it's yours to carry, but a person had to hand it to you. If your badge ever does something I don't like, that's on me, and I can revoke it."

**Caption (bottom):** *An agent cannot self-mint. Identity on the floor is something a human hands you — a tap, a printed badge, a name that starts with `agt_`.*
